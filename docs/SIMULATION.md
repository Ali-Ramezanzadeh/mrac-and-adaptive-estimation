# Simulation and reproduction

## Software

The six Simulink archives identify **MATLAB R2022b**. Use MATLAB with Simulink to open them. Static inspection found standard Simulink blocks and one embedded MATLAB Function in HW2. No external model references, data-file inputs, or executable model callbacks were found. HW1 retains a Simscape product metadata entry, but no Simscape blocks were identified; Simscape is not a confirmed requirement.

The HW6 Live Script uses base MATLAB numerical operations and plotting. Complete runtime/toolbox compatibility has not been tested. No MATLAB executable was available in the preparation environment.

## Open and run a saved model

Set the repository as MATLAB's current folder, then:

```matlab
addpath('scripts');
open_homework(2);
```

The helper opens the model; it does not start a simulation, edit parameters, or save changes. Inspect the relevant subsystem, reference/excitation signals, initial conditions, gains, and Scopes, then click Run.

For direct opening, HW1 is homeworks/hw-01/matlab/Adaptive.slx; HW2–6 are HW2.slx through HW6.slx in their corresponding homework folders. After a model is loaded, `sim('HW2')` runs its saved configuration. See the official [load_system](https://www.mathworks.com/help/simulink/slref/load_system.html) and [sim](https://www.mathworks.com/help/simulink/slref/sim.html) documentation.

Each model stores several subsystems or experiment choices. A single saved configuration should not be assumed to recreate every report figure. For comparisons, keep the same excitation, initial conditions, adaptation gains, and solver settings, and record changes explicitly.

## HW6 MATLAB experiment

Open homeworks/hw-06/matlab/HW6.mlx in MATLAB's Live Editor, or read/run its code companion HW6_code_export.m. Execute sections in order because later sections reuse earlier variables.

The script uses Ts=0.1 and a 40-second time vector, whereas HW6.slx uses Ts=0.01 and a saved 10-second stop time. The script starts with theta_true=[0;0.01;0;2;0;1]. Static block-connection inspection shows the model's observed output yt is generated by a direct regression product with feedback coefficient -0.01, rather than the script's +0.01. The model also contains a separate canonical-state chain; reconcile that chain and its regression output before comparing both plant representations. These are distinct saved configurations, not simply the same experiment at different sample rates.

The saved SLX Product6 block also multiplies phi, phi'*phi, and the prediction error, whereas normalized PA in the script divides by phi'*phi. Use the Live Script/code export for the documented algorithm comparisons; review the SLX update before using it as a normalized-PA implementation.

The script calls randn without fixing a seed, so repeated runs can produce different trajectories. Its exported .m file preserves the twelve original code sections; original Live Editor outputs remain in the .mlx. To perform a controlled comparison, set and record a seed before generating inputs and use the same realization for every estimator.

## Read the report with the implementation

The homework guides distinguish original reported results from static source checks. HW2 has an incomplete English draft; its Persian PDF is the full source. HW3–4 use new English technical summaries alongside Persian originals. HW5–6 have multiple original PDF date variants, preserved in the archive. Report cover dates and LaTeX `today` values are not reliable simulation-run timestamps.

No new numerical error metric or stability certificate is claimed. Review the identified equation and parameter-ordering discrepancies before reusing a derivation in another design.
